# Library
- This is a simple Library Application that uses a book constructor to create a book and
uses a myLibrary array to store books.
- It has a status feature to determine if a person red a book or not. This feature uses the concept of prototype
inheritance to extend the status to allow it toggle between true or false.

# Concepts
- DOM manipulation
- Use of constructors.
- Prototype Inheritance
- Looping
- Factory Function Usage
- CSS styling

# Struggles
- Difficulty using prototype function
- DOM element organisation.

# Solution
- Called the prototype when using a status button which enabled me to switch between the two different states of "READ" OR "NOT READ"
- I drew out the flow of how the different processes were supposed to flow on paper which enabled me properly place DOM elements and 
  call Factory functions.
